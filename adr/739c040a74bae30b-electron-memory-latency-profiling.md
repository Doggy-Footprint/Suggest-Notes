# Electron 환경 메모리/레이턴시 프로파일링 및 최적화

## Context

Obsidian은 Electron(Chromium) 기반이며, 사용자 다수가 사무용 노트북 등 리소스가 제한된 환경에서 실행한다. Suggest Notes는 타이핑할 때마다 인라인 제안을 계산하므로, 최적화하지 않으면 큰 볼트(vault)에서 타이핑 중 랙이나 메모리 사용량 급증을 유발할 수 있다.

## Decision

Chromium 프로파일링 도구를 이용해 Electron/Obsidian 환경에서 직접 메모리 사용량과 레이턴시를 측정하고, 사무용 노트북에서도 매끄럽게 동작하는 것을 목표로 최적화한다.

## Alternatives

- **일반적인 Node.js 벤치마크만으로 성능을 추정**: Electron/Chromium 환경의 실제 렌더러 프로세스 특성(메모리 관리, GC 타이밍)과 차이가 있어 실사용 환경을 대표하지 못한다고 판단해 기각.
- **최적화 없이 기능 우선 개발 후 필요시 대응**: 타이핑 중 실행되는 기능 특성상 지연이 사용자 경험에 직접적이고 즉각적으로 영향을 주므로, 사후 대응보다 설계 단계에서부터 목표 환경(사무용 노트북)을 기준으로 최적화하기로 결정.

## Consequences

- 대형 볼트/많은 노트를 추적 대상으로 지정해도 타이핑 흐름이 끊기지 않는 수준의 성능 확보
- Chromium 프로파일링 결과와 최적화 과정은 별도 글로 정리됨 (README 관련 글 참고)
- 향후 기능 추가 시에도 Electron 환경 기준의 프로파일링을 재확인할 필요가 있음
